# Threads in Operating Systems – MCQs

## EASY MCQs

1. A thread is also known as:  
   A. Heavyweight process  
   B. Independent process  
   C. Lightweight process  
   D. Kernel process  

2. A thread is the smallest unit of:  
   A. Memory  
   B. Scheduling  
   C. CPU execution  
   D. Program storage  

3. Threads of the same process share:  
   A. Stack  
   B. Registers  
   C. Program counter  
   D. Memory and code  

4. Which component keeps track of the next instruction of a thread?  
   A. Stack  
   B. Register  
   C. Program Counter  
   D. Thread ID  

5. Which has lower creation overhead?  
   A. Process  
   B. Thread  
   C. Kernel  
   D. Scheduler  

6. Which type of thread is managed at user level?  
   A. Kernel thread  
   B. Hybrid thread  
   C. User-level thread  
   D. System thread  

7. Which function is used to create a thread in POSIX?  
   A. fork()  
   B. CreateProcess()  
   C. pthread_create()  
   D. exec()  

8. Threads improve application responsiveness by:  
   A. Increasing memory usage  
   B. Blocking processes  
   C. Executing tasks concurrently  
   D. Reducing CPU speed  

9. Which of the following is NOT a component of a thread?  
   A. Stack  
   B. Program counter  
   C. Registers  
   D. Disk space  

10. Which application commonly uses multithreading?  
    A. Text editor  
    B. Web browser  
    C. Compiler  
    D. Loader

## MEDIUM MCQs

11. If one user-level thread blocks, then:  
    A. Other threads continue  
    B. Kernel handles it  
    C. Entire process blocks  
    D. CPU utilization increases  

12. Kernel-level threads are:  
    A. Invisible to OS  
    B. Managed by thread library  
    C. Scheduled by kernel  
    D. Faster to create  

13. Which thread model maps many user threads to one kernel thread?  
    A. One-to-One  
    B. Many-to-One  
    C. Many-to-Many  
    D. One-to-Many  

14. Which thread model provides true parallelism?  
    A. Many-to-One  
    B. User-level  
    C. One-to-One  
    D. Single-thread  

15. Which thread type has higher management overhead?  
    A. User-level thread  
    B. Kernel-level thread  
    C. Hybrid thread  
    D. Green thread  

16. Which of the following is a disadvantage of kernel threads?  
    A. Poor CPU utilization  
    B. High creation cost  
    C. Entire process blocks  
    D. No parallelism  

17. Race condition occurs when:  
    A. Threads are synchronized  
    B. Only one thread executes  
    C. Multiple threads access shared data simultaneously  
    D. CPU is idle  

18. Which problem occurs when threads wait indefinitely for resources?  
    A. Starvation  
    B. Thrashing  
    C. Deadlock  
    D. Paging  

19. Starvation in threads means:  
    A. Thread consumes all CPU  
    B. Thread never gets CPU  
    C. Thread blocks process  
    D. Thread terminates  

20. Which is used to solve thread safety issues?  
    A. Paging  
    B. Scheduling  
    C. Mutexes and semaphores  
    D. Context switching
